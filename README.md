# Waggle-Robot-Monkey-Desktop-Pet
Bring your desktop to life with a robotic monkey that reacts, roams, and plays with a draggable ball! 🐒 Built with Python and PyQt5, this interactive pet features animated movement, expressive reactions, sleeping, and hanging behaviour.
## Installation and Running

### Windows application

1. Open the [Releases page](https://github.com/Akshita029/Waggle-Robot-Monkey-Desktop-Pet/releases).
2. Download `Waggle-Robot-Monkey.zip`.
3. Extract the ZIP file.
4. Open the extracted folder and run `DesktopPet.exe`.
5. Keep the application files and asset folders together.

### Running from source

**Requirements:** Python and PyQt5.

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Install PyQt5:

   ```bash
   python -m pip install PyQt5
   ```

4. Run the program:

   ```bash
   python "desktop pet.py"
   ```

Make sure the image assets are available at the paths expected by the code.
